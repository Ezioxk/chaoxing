# 超星学习控制台

## 启动

Windows 双击项目根目录中的 `start_webui.bat`，会自动打开默认浏览器。也可以手动打开：

<http://127.0.0.1:8080>

启动窗口需要保持运行。浏览器可以关闭再打开；关闭浏览器不会停止后台任务。按启动窗口中的 `Ctrl+C` 可结束服务与当前后台任务。

也可以在项目目录运行：

```powershell
py -3 webui.py
```

需要 Python 3.13 或更高版本。如果首次运行提示缺少依赖：

```powershell
py -3 -m pip install -r requirements.txt
```

端口被占用时：

```powershell
py -3 webui.py --port 8082
```

对应打开 <http://127.0.0.1:8082>。不需要启动 `app.py`、Celery 或 Redis。

## 页面操作

1. **运行设置 → 账号与运行**：输入手机号、密码，点击「连接账号并读取课程」。已有根目录 `cookies.txt` 时，也可勾选「使用已有 Cookie 登录」。登录只读取课程，不自动开始处理。
2. **我的课程**：按课程名称、教师或 ID 搜索，点击「查看章节」读取平台章节。勾选需要处理的课程，点击「开始运行」。未勾选、课程失效或课程不匹配时会阻止启动。
3. **运行设置 → 运行偏好**：可设置 1–2 倍速、1–8 个并发章节，未开放章节选择跳过或最多重试 3 次。点击保存后，在下次操作中生效。
4. **题库配置**：默认不使用题库。选择提供方后填写对应 Token、端点或模型等。默认仅保存答案、手动检查后提交。题目覆盖率不代表答题正确率。
5. **完成通知**：默认关闭。需要时填写服务与 URL，任务本轮处理结束后调用原通知模块；停止操作不会发送完成通知。
6. **运行日志**：查看实时输出、切换信息/警告/错误、导出当前保留的日志。清空只影响页面显示。
7. **停止**：点击底部「停止」，等待状态显示「已停止」。可以重新选择课程运行。

## 如何判断完成

进度条表示本轮章节遍历比例。成功、跳过、失败分别计数；只要有跳过或失败，就会显示「部分完成」。原程序返回成功并不保证平台上的所有任务均已完成，尤其在未启用题库时。请在运行后重新读取章节，必要时在学习通确认。

## 本地文件

| 文件 | 内容 |
| --- | --- |
| `.webui/settings.json` | 普通界面设置；不保存密码、题库密钥、通知密钥 |
| `.webui/cookies.txt` | 界面的登录会话 Cookie |
| `.webui/demo/` | 演示模式独立设置目录 |
| `config.ini` | 原命令行配置；界面不自动导入或改写 |
| `cookies.txt` | 原命令行 Cookie；仅在主动选择已有 Cookie 登录时使用 |

密码和密钥留空会保留当前服务内存中的值，重新输入可替换。退出登录清除内存中的全部敏感凭据与界面 Cookie，原根目录 Cookie 保留。服务重启后，密码与题库、通知密钥需重新填写；也可使用仍有效的界面 Cookie 登录。

## 无账号体验

```powershell
py -3 webui.py --demo --port 8081
```

打开 <http://127.0.0.1:8081>。进入运行设置，点击连接账号即可加载演示课程，随后可以试用课程选择、章节预览、运行进度和停止。演示模式不连接超星；全程显示模拟数据提示。

## 测试

```powershell
py -3 -m unittest discover -s tests -v
```

测试使用项目 `.webui/tests/` 下的隔离目录，不需要账号，不向平台发送学习任务。程序结构和改动原因见 [程序分析](程序分析.md)。
